**实施日期**: 2026-04-15

## 一、需求背景

根据用户要求，参考"提取引擎"的交互模式，为**算法模块**和**实验设计功能**添加前端可点按确认或补充的交互功能。

### 核心需求
1. **用户主导流程**：用户先选择算法，再指定数据文件
2. **空输入处理**：如果用户输入为空，展示算法列表供选择
3. **可视化选择**：每个算法右侧带有绿色运行箭头 ▶
4. **文件选择器**：点击运行后弹出文件选择器，支持多种方式选择文件
5. **与提取模块一致**：保持相同的交互风格和视觉设计

---

## 二、实施方案

### 交互流程设计

```
用户输入 → 判断是否指定算法
    ├─ 是 → 显示算法确认卡片 → 点击运行 → 文件选择器
    └─ 否 → 显示算法列表卡片 → 点击运行箭头 → 文件选择器
                                                    ↓
                                            选择文件（三种方式）
                                                    ↓
                                            执行算法 → SSE推送进度
                                                    ↓
                                            显示结果卡片
```

## 三、实施细节

### 3.1 后端API实现（app.py）

#### 新增路由

**1. `/api/list_algorithms` [GET]**
- 功能：获取所有可用算法列表
- 返回：算法名称、描述、参数、标签、图标
- 增强：为每个算法添加标签和图标信息

**2. `/api/parse_algorithm` [POST]**
- 功能：解析用户输入，识别算法名称
- 输入：`{"user_input": "使用数据统计分析"}`
- 输出：
  - 找到算法：`{"algorithm_found": true, "algorithm": "data_statistics", ...}`
  - 未找到：`{"algorithm_found": false, "available_algorithms": [...]}`
- 实现：使用关键词匹配（统计、归一化、光谱等）

**3. `/api/recent_files` [GET]**
- 功能：获取最近使用的CSV文件列表
- 扫描目录：`temporal/` 和 `extract/`
- 返回：文件路径、名称、大小、修改时间
- 排序：按修改时间倒序，返回最近10个

**4. `/api/run_algorithm` [POST]**
- 功能：执行指定算法
- 输入：
  ```json
  {
    "algorithm": "data_statistics",
    "file_path": "temporal/extraction.csv",
    "params": {"include_correlation": true}
  }
  ```
- 流程：
  1. 验证文件存在
  2. 检查任务队列
  3. 启动后台线程执行
  4. 返回任务ID

### 3.3 软件管理器（core/software_manager.py）

#### 新增方法：`run_algorithm_on_csv`

**功能**：读取指定CSV文件并执行算法，通过task_manager推送进度

**参数**：
- `algorithm_name`: 算法名称
- `csv_path`: CSV文件路径
- `params`: 算法参数
- `task_manager`: 任务管理器实例

**执行流程**：

```python
1. 推送开始消息 → "开始分析"
2. 读取CSV数据 → _read_csv_as_columns()
3. 推送数据读取完成 → "成功读取 N 列数据"
4. 执行算法 → run_algorithm()
5. 保存结果到 results/ 目录
   - 覆盖写：analysis_{algorithm}.json
   - 时间戳存档：analysis_{algorithm}_{timestamp}.json
6. 推送完成消息 → 包含结果和文件路径
```

**结果保存格式**：

```json
{
  "algorithm": "data_statistics",
  "file_path": "temporal/extraction.csv",
  "params": {"include_correlation": true},
  "timestamp": "20260415-143022",
  "result": {
    "mean": 15.68,
    "std": 2.34,
    ...
  },
  "success": true
}
```
