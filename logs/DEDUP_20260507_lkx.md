## 1. 概述

实现提取结果去重功能：在所有页面提取完成后、CSV 写入前，按实体名称（fields[0]）精确匹配去重，合并重复行的信息。

| `config.json` | 同上（实际值） |

## 4. 去重算法

1. **识别实体键**: fields[0]（如"钝化剂名称"）
2. **规范化**: strip（默认）去首尾空格；可选 lower（小写）/ strict（不转换）
3. **分组**: 按规范化后的实体键分组
4. **合并**: 每组重复行合并为一条
   - 实体键: 取规范化后的值
   - 其他字段: 取最长非空值（longest）或第一个非空值（first_non_empty）
   - `_source_doc`: 收集去重后用 "; " 拼接
   - 添加 `_occurrence_count`（出现次数）和 `_source_docs`（来源文档列表）
5. **排序**: 按实体键字母序输出

## 5. 配置

| Key | 默认值 | 说明 |
|-----|--------|------|
| `DEDUP_ENABLED` | `true` | 启用/禁用去重 |
| `DEDUP_NORMALIZE` | `"strip"` | "strip" / "lower" / "strict" |
| `DEDUP_MERGE_STRATEGY` | `"longest"` | "longest" / "first_non_empty" |
| `DEDUP_ADD_METADATA` | `true` | 是否添加出现次数/来源文档列 |
