# 前端提取模式切换功能使用说明

## 功能说明

在主界面的"文献提取模式"中，现在可以直接切换PDF提取模式了！

## 使用步骤

### 1. 启动服务
```bash
python app.py
```

### 2. 打开主界面
访问：`http://127.0.0.1:5000`

### 3. 选择文献提取模式
1. 点击左下角的 **+** 按钮
2. 选择 **📄 文献提取模式**

### 4. 切换提取模式
在输入框上方会显示：
```
📄 文献提取 ⚙️ ×
```

点击 **⚙️** 图标，会弹出提取模式选择器：

```
┌─────────────────────────────────────┐
│ 📄 选择提取模式                      │
├─────────────────────────────────────┤
│ 🎯 混合模式 [推荐]                   │
│ 智能判断内容复杂度，节省60-80%成本    │
├─────────────────────────────────────┤
│ 🖼️ 纯视觉模式 [高精度]               │
│ 所有页面用Vision API，准确但成本高    │
├─────────────────────────────────────┤
│ 📝 纯文本模式 [快速]                 │
│ 提取文本分析，快速便宜但可能丢失图表   │
└─────────────────────────────────────┘
```

### 5. 点击选择模式
- 点击任意模式，系统会立即切换
- 聊天框会显示：`✅ 已切换到 混合模式`
- 当前选中的模式会高亮显示（蓝色背景）

### 6. 开始提取
切换模式后，正常输入提取指令：
```
帮我搜寻：FAPbI3钙钛矿的钝化剂
```

系统会使用你选择的模式进行提取。

## 三种模式说明

### 🎯 混合模式（推荐）
- **成本**：约38%（相比纯Vision）
- **准确性**：⭐⭐⭐⭐
- **适用**：大部分科学文献
- **特点**：智能判断页面复杂度，自动选择最优API

### 🖼️ 纯视觉模式
- **成本**：100%（基准）
- **准确性**：⭐⭐⭐⭐⭐
- **适用**：包含大量图表、化学式的文献
- **特点**：所有页面都用Vision API，保证最高准确性

### 📝 纯文本模式
- **成本**：约20%（相比纯Vision）
- **准确性**：⭐⭐⭐
- **适用**：纯文字综述、理论部分
- **特点**：快速便宜，但会丢失图表信息

## 常见问题

**Q: 切换模式后需要刷新页面吗？**
A: 不需要，切换后立即生效。

**Q: 切换模式会影响正在进行的提取任务吗？**
A: 不会，只影响新启动的提取任务。

**Q: 如何知道当前是什么模式？**
A: 打开模式选择器，当前模式会有蓝色背景高亮。

**Q: 可以在提取过程中切换模式吗？**
A: 可以切换，但只对下一次提取任务生效。
