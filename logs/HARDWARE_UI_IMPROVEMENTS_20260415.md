## 🎯 详细更新内容

### 1. 单步控制面板交互方式优化

**问题背景**:
- 原有设计：双击整个工具行才能展开参数面板
- 用户反馈：操作不够直观，容易误触运行按钮

**优化方案**:
- ✅ 单击最左边的小三角形（▶）可以快速展开/收起参数面板
- ✅ 其他位置保持双击展开的方式（兼容原有习惯）
- ✅ 更新底部状态栏提示文字：`就绪 — 单击 ▶ 展开工具，点击右侧 ▶ 执行`

**修改文件**:
- `templates/index.html` (行 1509, 406)

**代码变更**:
```javascript
// 为小三角形添加单击事件
<span class="tool-arrow" onclick="event.stopPropagation(); toggleToolExpand('${tool.name}')">▶</span>
```

**用户体验提升**:
- 操作更直观，减少误操作
- 提高参数配置效率
- 保持向后兼容（双击仍然有效）

### 2. 硬件函数调用日志

**问题背景**:
- 硬件调试困难，无法追踪函数调用历史
- 出现问题时难以定位是哪个硬件函数被调用
- 缺少参数记录，无法复现问题

**优化方案**:
- ✅ 在 `core/hardware_controller.py` 中添加日志记录
- ✅ 每次硬件函数调用时自动输出工具名称和参数
- ✅ 同时使用 `logging` 模块和 `print` 输出（日志文件 + 控制台）
- ✅ 未修改 `hardware/tools.py`，保持底层代码简洁

**修改文件**:
- `core/hardware_controller.py` (行 1-16, 203-230)

**日志格式**:
```
[硬件调用] 工具: set_temperature, 参数: {'target': 150.0}
[硬件调用] 工具 set_temperature 执行完成
```

**代码变更**:
```python
# 添加日志模块
import logging
logger = logging.getLogger(__name__)

# 在 execute_tool_call() 方法中添加日志
logger.info(f"[硬件调用] 工具: {tool_name}, 参数: {params}")
print(f"[硬件调用] 工具: {tool_name}, 参数: {params}")
# ... 执行硬件函数 ...
logger.info(f"[硬件调用] 工具 {tool_name} 执行完成")
```

**开发者体验提升**:
- 实时追踪硬件调用历史
- 快速定位问题硬件函数
- 完整记录调用参数，便于复现和调试
- 支持日志文件持久化存储
