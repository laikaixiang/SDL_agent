## 📋 更新概述

本次更新为SDL_agent系统实现了**单步控制面板**功能，提供了全新的可视化硬件控制交互界面。用户现在可以通过图形化面板直接选择硬件工具、配置参数并执行，无需通过自然语言输入和LLM解析，大幅提升了硬件控制的效率和准确性。

---

## 🎯 核心功能

### 功能特性

- ✅ **可视化工具目录**: 6个硬件工具以列表形式展示
- ✅ **双击展开/收起**: 查看和配置工具参数
- ✅ **参数类型提示**: 显示类型、必填/可选、默认值
- ✅ **一键执行**: 点击绿色▶按钮直接执行
- ✅ **并发控制**: 同一时间只能运行一个工具
- ✅ **状态反馈**: 底部状态栏实时显示执行状态
- ✅ **结果回显**: 执行结果同步显示在聊天框

### 支持的硬件工具

1. `set_temperature` - 设置设备温度
2. `move_robot_arm` - 移动机械臂到指定位置
3. `do_experiment` - 执行旋涂实验
4. `save_experiment_step` - 注册一步旋涂实验参数
5. `start_experiment` - 启动已注册的多步实验序列
6. `collect_spectrum` - 启动光谱仪数据采集

## 🔧 技术实现

### 1. 后端更新 (`app.py`)

#### 新增API路由

```python
@app.route('/api/hardware_tools', methods=['GET'])
def get_hardware_tools():
    """返回所有注册的硬件工具及其参数Schema"""
```

**功能**: 返回所有已注册的硬件工具及其完整参数Schema  
**位置**: 在 `/api/hardware_status` 路由之后  
**数据来源**: `hardware_controller.agent.hardware_tools`

**返回格式**:
```json
{
  "tools": [
    {
      "name": "工具名称",
      "description": "工具描述",
      "params": {
        "参数名": {
          "type": "类型",
          "description": "描述",
          "required": true/false,
          "default": 默认值
        }
      }
    }
  ]
}
```

- **旧**: `setMode('hardware_single', '硬件控制：', '🔧 单步控制')`
- **新**: `openStepPanel()`
- **效果**: 从文本输入模式改为图形化面板模式

#### 2.4 JavaScript功能新增

##### 全局变量

```javascript
let stepPanelTools = [];      // 工具列表缓存
let stepRunning = false;       // 执行状态标志
let stepExpandedTool = null;   // 当前展开的工具名
```

##### 核心函数

| 函数名 | 功能 | 关键逻辑 |
|--------|------|----------|
| `openStepPanel()` | 打开面板 | 关闭菜单 → 添加'open'类 → 进入split-mode → 获取工具列表 |
| `closeStepPanel()` | 关闭面板 | 移除'open'类 → 延迟检查PDF状态 → 退出split-mode |
| `fetchStepTools()` | 获取工具列表 | 调用`GET /api/hardware_tools` → 缓存数据 → 渲染 |
| `renderStepTools()` | 渲染工具列表 | 遍历工具 → 生成HTML → 恢复状态 |
| `renderParamFields()` | 渲染参数字段 | 根据params生成输入框 → 标注必填/可选 → 预填默认值 |
| `toggleToolExpand()` | 展开/收起工具 | 切换`stepExpandedTool` → 重新渲染 |
| `runTool()` | 执行工具 | 收集参数 → 验证必填 → 调用API → 更新状态 → 回显结果 |
| `disableAllRunBtns()` | 禁用所有按钮 | 当前工具显示⏳ → 其他工具disabled |
| `enableAllRunBtns()` | 恢复所有按钮 | 移除running类 → 恢复▶ |
| `setStepStatus()` | 更新状态栏 | 设置文本 → 切换背景色 |

## 🔄 数据流

```
用户点击"单步控制"
  ↓
openStepPanel()
  ↓
GET /api/hardware_tools (首次)
  ↓
渲染工具列表
  ↓
用户双击工具行
  ↓
toggleToolExpand() 展开参数区
  ↓
用户填写参数并点击▶
  ↓
runTool() 收集参数
  ↓
POST /api/chat {action: 'start_hardware', tool_calls: [...]}
  ↓
handle_hardware_execute()
  ↓
hardware_controller.execute_tool_calls()
  ↓
HardwareAgent.execute_tool_call()
  ↓
hardware/tools.py 底层函数
  ↓
返回结果
  ↓
更新状态栏 + 追加消息到聊天框
```

- **z-index: 50**: 覆盖PDF面板 (默认z-index: 0)
- **低于模态框**: 不遮挡文件选择器 (z-index: 1000+)
