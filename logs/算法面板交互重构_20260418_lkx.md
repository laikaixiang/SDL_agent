# SDL_agent 工作日志 — 算法面板交互重构

**更新时间**: 2026年4月18日  
**更新人员**: lkx  
**版本标识**: 算法面板 UI 交互重构，引入中文名、文件选择器复用

---

## 📋 更新概述

本次更新对左侧算法面板（`algorithm_panel.js`）进行了两轮交互重构，主要包括：算法卡片布局调整、中文名支持、交互模式改为单击选中/双击展开，以及将输入输出文件选择统一复用主页面文件选择器模态框。

---

## 🎯 核心变更

### 1. 算法注册表新增 `chinese_name` 字段

**涉及文件**：`software/algorithms/base.py`、各算法文件

- `BaseAlgorithm` 新增类属性 `chinese_name: str = ""`
- `get_info()` 返回值中加入 `chinese_name`，`/api/list_algorithms` 同步透传
- 各算法中文名对照：

| 算法 `name` | `chinese_name` |
|---|---|
| `data_statistics` | 数据统计分析 |
| `data_normalization` | 数据归一化 |
| `spectrum_analysis` | 光谱分析 |
| `bayesian_optimization` | 贝叶斯优化 |

### 2. 算法卡片布局调整（第一轮）

**涉及文件**：`algorithm_panel.js`、`main.css`

- 移除图标，卡片行改为：`[+按钮] [中文名标题] [›展开按钮]`
- `+` 按钮（绿色）：添加至实验设计
- `›` 按钮：展开/收起详情，展开时旋转 90° 变为向下箭头（CSS `transform: rotate(90deg)` 动画）
- 展开详情区显示完整 `description` 文本 + 标签

### 3. 交互模式重构（第二轮）

**涉及文件**：`algorithm_panel.js`、`main.css`

旧模式：单击标题区 → 直接执行（打开文件选择器）  
新模式：
- **单击**：选中高亮（`.selected` 类，绿色边框+阴影，更新 `selectedAlgorithm`）
- **双击**：展开/收起详情（220ms 防抖计时器区分单双击）

展开详情区新增两行文件配置：
- **输入文件**：显示已选文件名，点击"选择"按钮唤出文件选择器
- **输出目录**：显示已选目录名（默认为当前会话 `results/`），点击"选择"按钮唤出目录选择器

### 4. 文件选择器模态框扩展

**涉及文件**：`templates/index.html`、`analysis.js`、`main.css`

复用主页面回形针所用的 `#file-selector-modal`，避免重复造轮子：

- `showFileSelector(callback)` 新增可选回调参数：有回调时结果传给回调，无回调时保持原有"执行算法"行为（向下兼容）
- 新增 `showOutputDirSelector(callback)`：以目录模式打开同一模态框，隐藏文件相关标签页，显示新增的"选择目录"标签页
- 模态框新增第四个标签页 `dirs`（默认隐藏），加载 `/api/browse_output_dirs` 返回的目录列表
- 浏览标签页新增拖拽上传支持（`ondragover` / `ondrop`），拖入 CSV 文件直接触发回调

### 5. 新增后端 API

**涉及文件**：`app.py`

| 路由 | 说明 |
|---|---|
| `GET /api/browse_csv` | 列出可用输入 CSV：当前会话 `extract/` + `temporal/` + `const_data/extract/` |
| `GET /api/browse_output_dirs` | 列出输出目录：当前会话 `results/`（默认★）+ `const_data/result/` 子文件夹 |
