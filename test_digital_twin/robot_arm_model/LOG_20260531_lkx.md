## 第三轮变更 — 修复拖动散架问题 (2026-05-31)

### 问题

Three.js `DragControls` 的 `raycaster.intersectObjects(_objects)` 在射线检测时会穿透 Group 返回子 Mesh（如载玻片、滴管孔位）。DragControls 直接移动 `intersect.object`（子 Mesh），导致盒子散架。

### 解决方案

移除 `DragControls`，用自定义 `setupModuleDrag()` 替代：

- `findModuleGroup(intersects)`: 从射线命中的子对象向上遍历 `parent` 链，找到属于 `draggableModules` 的顶层 Group
- 点击载玻片 → 自动找到载玻片盒 Group → 整体拖动
- 点击滴管孔 → 自动找到滴管头盒 Group → 整体拖动
- 点击桌面网格线 → 自动找到桌面 Group → 整体拖动
- `setupModuleDrag()` 仅在初始化时调用一次（不随 rebuild 重复注册），`findModuleGroup` 动态检查 `draggableModules` 数组，重建模块后自动生效

### 修改文件

- `robot_arm_model/templates/index.html`:
  - 移除 `import { DragControls }`，移除 `dragControlsInstance` 变量
  - 新增 `setupModuleDrag()` + `findModuleGroup()` + `rebuildModuleDrag()` (no-op)
  - `rebuildModule` 中调用 `rebuildModuleDrag()` 替代 `rebuildDragControls()`

## 详细变更

### 1. 五大模块定义

| # | 模块 | physical | 说明 |
|---|------|----------|------|
| 1 | 机械臂 (robotArm) | false | 只读信息面板，显示 DH 参数、关节限位等 |
| 2 | 桌面 (desktop) | false | 网格尺寸/平台尺寸配置 |
| 3 | 载玻片盒 (slideBox) | true | 可拖拽，新增 slideW/slideL 自定义载玻片尺寸 |
| 4 | 匀胶机 (spinCoater) | true | 可拖拽（不变） |
| 5 | 滴管头盒 (dropperBox) | true | 可拖拽（不变） |

### 2. 数据结构重构

- 引入 `moduleDefs` 统一管理所有模块元数据（label, physical, defaultPos, defaultConfig）
- 引入 `moduleOrder` 数组定义 tab 顺序
- 移除旧的分散结构：`defaultPositions`, `moduleLabels`, 独立 `moduleConfigs`
- runtime `moduleConfigs` 从 `moduleDefs[type].defaultConfig` 初始化

### 3. 载玻片盒新增参数

- **slideW**: 载玻片宽度 (X方向), 默认 25mm, 范围 5-100mm
- **slideL**: 载玻片长度 (Z方向), 默认 75mm, 范围 10-150mm
- `buildSlideBox()` 使用 `cfg.slideW` / `cfg.slideL` 替代硬编码值

### 4. 位置手动输入

- 每个 physical 模块新增 X / Z 输入框，可直接键入精确坐标
- `onSetPosition()` 函数：校验范围 → snapToGrid → 更新 3D 位置
- 拖拽与手动输入双向同步（拖拽后输入框自动更新）

### 5. 配置面板 UI

- `renderModuleConfigUI()` 按模块类型渲染不同控件：
  - robotArm: 只读信息（型号/构型/参数/操作指引）
  - desktop: 网格尺寸 + 平台尺寸 input
  - 物理模块: 数量/分布/缩放/间隔 + slideBox专属 slideW/slideL + 位置 X/Z
- `onConfigChange()` 区分 physical/non-physical 分支处理

### 6. 其他

- `rebuildModule()` 增加 `physical` 检查，非物理模块跳过 3D 重建
- `switchModuleTab()` 使用 `moduleOrder` 遍历，支持 5 个 tab
- 默认激活 tab 改为 robotArm
