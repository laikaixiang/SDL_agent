## 变更总览

将平台数字孪生从 3 个静态 3D 模型重构为 **6 模块系统**，支持编辑模式、参数化配置、多实例、持久化存储。

## 一、模块体系 (6 modules)

| # | 模块 | 类型 | 说明 |
|---|------|------|------|
| 1 | 机械臂 (robotArm) | 只读信息 | Dobot M1Pro 参数展示 |
| 2 | 桌面 (desktop) | 物理/可拖拽 | 平台底板+网格+边界线，尺寸可配 |
| 3 | 载玻片盒 (slideBox) | 物理/可拖拽 | 盒子+载玻片，片尺寸 W×L 可定义 |
| 4 | 匀胶机 (spinCoater) | 物理/可拖拽 | 底座+转盘+卡盘，支持多台 |
| 5 | 滴管头盒 (dropperBox) | 物理/可拖拽 | 8×12=96孔网格，行列间隔可分别定义 |
| 6 | 溶液瓶托盘 (solutionTray) | 物理/可拖拽 | 4×5=20圆形凹槽，瓶直径可定义 |

## 二、数据结构

```javascript
moduleDefs      // 静态元数据：label, physical, defaultPos, defaultConfig, sizeRange, spacingRange
moduleConfigs   // 运行时配置（从 defaultConfig 初始化，编辑后更新）
moduleOrder     // ['robotArm', 'desktop', 'slideBox', 'spinCoater', 'dropperBox', 'solutionTray']
moduleGroups    // { type: [THREE.Group, ...] }  — 多实例数组
modulePositions // { type: [THREE.Vector3, ...] } — 多实例位置数组
draggableModules // 扁平列表，用于射线检测
builders        // { type: builderFn } — 参数化 3D 构建函数
```

## 三、交互模型

### 编辑模式 OFF（默认）

- 面板显示 **6 模块摘要列表**（名称、参数概要、实例数、位置）
- **双击模块名** → 添加新实例（桌面除外，仅1个）
- **× 按钮** → 删除该类型最后添加的实例（≥2个时显示）
- **右键 3D 模块** → 删除该实例
- **拖拽** 3D 模块 → 自由移动，50mm 网格吸附
- **手动输入位置** → X/Z 坐标输入框

### 编辑模式 ON

- 显示模块 Tab 栏，可切换编辑
- 每模块独立参数面板：
  - 数量、分布方式、列/行数（滴管头盒、溶液瓶托盘）
  - 整体缩放（滑块，范围由模块定义）
  - 间隔（载玻片盒=横/纵，滴管头盒/溶液瓶托盘=列/行，匀胶机=单一）
  - 载玻片宽×长（仅载玻片盒）、瓶直径（仅溶液瓶托盘）
  - 位置 X/Z 输入
- 参数修改 → 该类型**所有实例**统一重建

## 六、自定义拖动系统

**问题**: Three.js `DragControls` 射线检测穿透 Group 返回子 Mesh（载玻片、滴管孔），移动子对象导致盒子散架。

**方案**: 移除 DragControls，用 `setupModuleDrag()` 自定义实现：
- `findModuleGroup(intersects)`: 从射线命中对象沿 `.parent` 链向上查找，返回属于 `draggableModules` 的顶层 Group
- pointerdown → 射线 → 找顶层Group → pointermove 移动Group → pointerup 吸附+保存位置
- 点击任何子对象（载玻片、滴管孔、网格线）均自动定位到父模块整体拖动

## 七、配置持久化

### 文件: `platform_config.json`

存储所有物理模块的模板参数 + 实例位置数组：

```json
{
  "slideBox": {
    "quantity": 25, "distribution": "grid", "size": 1.0,
    "hSpacing": 4, "vSpacing": 4, "slideW": 25, "slideL": 25,
    "positions": [[100, -50], [200, -50]]
  }
}
```

### API 端点（在 `digital_twin.py`）

| 方法 | 路由 | 功能 |
|------|------|------|
| GET | `/api/platform_config` | 读取配置 |
| POST | `/api/platform_config` | 保存配置（前端「保存配置」按钮） |

### 前端流程

1. 页面加载 → `loadConfig()` → GET `/api/platform_config` → `applyConfig()` 合并到 `moduleConfigs` + `modulePositions`
2. 用户编辑 + 拖拽
3. 点击「保存配置」→ `collectConfig()` 收集所有参数+位置 → POST 写入文件
4. 刷新页面 → 自动恢复

兼容旧格式：`position: [x, z]` 自动转为 `positions: [[x, z]]`。
