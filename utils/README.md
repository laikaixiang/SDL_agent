# utils — 工具模块

通用工具函数和辅助类。

| 文件 | 说明 |
|------|------|
| `csv_writer.py` | CSV 文件写入工具 |
| `pdf_to_markdown.py` | PDF 转 Markdown 格式转换 |
| `config_loader.py` | 配置文件加载器（config.json + 环境变量覆盖） |
| `batch_processor.py` | 并发批处理器（ThreadPoolExecutor） |
| `pdf_metadata_extractor.py` | PDF 元数据提取器（标题/摘要/创新点/关键图） |
| `sse.py` | Server-Sent Events 响应封装 |
| `stream_adapter.py` | 流式响应适配器 |
